# คู่มือระบบคำนวณและบันทึกค่าสีตัวต้านทาน (Resistor Color Code Web App)

โปรเจกต์นี้คือเว็บแอปพลิเคชัน (Web App) สำหรับอ่านแถบสีตัวต้านทาน 4, 5, และ 6 แถบสี สามารถคำนวณสลับระหว่างแถบสีและค่าโอห์มแบบสองทิศทางได้ และยังเชื่อมโยงข้อมูลกับ **Google Sheets** เพื่อจัดเก็บข้อมูลประวัติการคำนวณโดยอัตโนมัติ

---

## 🛠️ โครงสร้างไฟล์ในโปรเจกต์
- [index.html](file:///C:/Users/terd2/.gemini/antigravity/scratch/resistor-sheet-app/index.html) - ไฟล์ส่วนติดต่อผู้ใช้ (Frontend) มี CSS ตกแต่งแนวโมเดิร์น (Glassmorphism) และฟังก์ชันคำนวณของฝั่ง Client
- [Code.gs](file:///C:/Users/terd2/.gemini/antigravity/scratch/resistor-sheet-app/Code.gs) - ไฟล์โค้ดสำหรับ Google Apps Script (Backend) เพื่อจัดการการเขียน/อ่านข้อมูลบน Google Sheet
- [server.js](file:///C:/Users/terd2/.gemini/antigravity/scratch/resistor-sheet-app/server.js) - เซิร์ฟเวอร์จำลองขนาดจิ๋วสำหรับการทดสอบในเครื่องคอมพิวเตอร์ของคุณ

## 🚀 วิธีการทดสอบรันบนเครื่องของคุณ (Local Preview)

คุณสามารถดูหน้าตาและฟีเจอร์การคำนวณได้ทันทีผ่านเซิร์ฟเวอร์จำลอง โดยในโหมดจำลองนี้ หน้าเว็บจะบันทึกประวัติไว้ที่ `localStorage` ของเบราว์เซอร์ของคุณชั่วคราว:

1. เปิด Terminal ในตำแหน่งโฟลเดอร์นี้
2. รันคำสั่งเริ่มเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
3. เปิดเบราว์เซอร์แล้วไปที่: [http://localhost:3000/](http://localhost:3000/)

## 📊 ขั้นตอนการติดตั้งและ Deploy บน Google Sheets (ใช้งานจริง)

ทำตามขั้นตอนด้านล่างนี้เพื่อเปิดใช้งานระบบร่วมกับ Google Sheets ของคุณ:

### ขั้นตอนที่ 1: สร้าง Google Sheets ใหม่
1. ไปที่ [Google Sheets](https://sheets.google.com) และสร้างตารางงานใหม่ (Spreadsheet เปล่า)
2. ตั้งชื่อไฟล์ตามต้องการ (เช่น *ระบบบันทึกค่าตัวต้านทาน*)

### ขั้นตอนที่ 2: เปิด Google Apps Script
1. ที่แถบเมนูด้านบนของ Google Sheet คลิกเลือก **ส่วนขยาย (Extensions)** -> **Apps Script**
2. หน้าต่างสำหรับเขียนโค้ดของ Google Apps Script จะเปิดขึ้นมาในแท็บใหม่

### ขั้นตอนที่ 3: ใส่โค้ด Backend
1. ในหน้าต่าง Apps Script จะมีไฟล์ที่ชื่อ `รหัส.gs` หรือ `Code.gs` ถูกสร้างขึ้นมาโดยอัตโนมัติ
2. ให้ลบโค้ดเริ่มต้นทั้งหมดออก
3. คัดลอกโค้ดทั้งหมดจากไฟล์ [Code.gs](file:///C:/Users/terd2/.gemini/antigravity/scratch/resistor-sheet-app/Code.gs) ในโปรเจกต์นี้ ไปวางแทนที่
4. กดรูป 💾 (บันทึกโครงการ) ด้านบน

### ขั้นตอนที่ 4: ใส่โค้ด Frontend UI
1. ในแถบด้านซ้ายของหน้าจอ Apps Script ให้คลิกปุ่ม **+** (เพิ่มไฟล์) ถัดจากเมนู "ไฟล์"
2. เลือก **HTML**
3. ตั้งชื่อไฟล์นี้ว่า `index` (จะได้ไฟล์ชื่อ `index.html` ห้ามสะกดผิด)
4. คัดลอกโค้ดทั้งหมดจากไฟล์ [index.html](file:///C:/Users/terd2/.gemini/antigravity/scratch/resistor-sheet-app/index.html) ในโปรเจกต์นี้ ไปวางทับเนื้อหาเริ่มต้นทั้งหมดในไฟล์ `index.html` ในหน้าสคริปต์
5. กดรูป 💾 (บันทึกโครงการ)

### ขั้นตอนที่ 5: เริ่มการ Deploy เว็บแอป
1. คลิกปุ่มสีน้ำเงินด้านขวาบนชื่อ **การใช้งานใช้ได้จริง (Deploy)** -> เลือก **การจัดการการใช้งานใช้ได้จริงใหม่ (New deployment)**
2. คลิกรูปเฟือง ⚙️ ข้างคำว่า "เลือกประเภท (Select type)" -> เลือก **เว็บแอป (Web app)**
3. ตั้งค่ารายละเอียดดังนี้:
   - **คำอธิบาย (Description):** *Resistor Calculator Web App v1*
   - **เรียกใช้งานในฐานะ (Execute as):** เลือก **ฉัน (Me / บัญชีอีเมลของคุณ)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** เลือก **ทุกคน (Anyone)** (เพื่ออนุญาตให้หน้าเว็บสื่อสารกับสคริปต์ชีตได้โดยตรง)
4. คลิกปุ่ม **การใช้งานใช้ได้จริง (Deploy)**
5. Google จะขอให้คุณอนุญาตการเข้าถึงข้อมูล (Authorize Access):
   - คลิก **อนุมัติสิทธิ์การเข้าถึง (Authorize Access)**
   - เลือกบัญชี Google ของคุณ
   - หากขึ้นหน้าจอเตือนความปลอดภัย ให้คลิกคำว่า **ขั้นสูง (Advanced)** ที่อยู่ด้านล่างซ้าย -> เลือก **ไปที่... (ไม่ปลอดภัย) / Go to ... (unsafe)**
   - คลิก **อนุญาต (Allow)**
6. เมื่อการติดตั้งเสร็จสิ้น คุณจะได้รับ **URL ของเว็บแอป (Web App URL)**
7. ให้คัดลอก URL นั้นไปเปิดใช้งานบนเบราว์เซอร์ได้เลย!

*หมายเหตุ: เมื่อคุณเปิดใช้งานผ่าน Web App URL ระบบจะเปลี่ยนสถานะจาก "Local Preview Mode" เป็น "เชื่อมต่อ Google Sheet แล้ว" โดยจะสร้างชีตชื่อ **"Resistor Log"** ให้คุณโดยอัตโนมัติเมื่อมีการบันทึกข้อมูลครั้งแรก!*
