โครงสร้างและฟิสิกส์การนำกระแสของ N-Channel JFET:
• ขั้วต่อ 3 ขั้ว: Drain (D), Source (S), Gate (G)
• ขั้ว Gate ต่อเข้ากับสารกึ่งตัวนำชนิด P ขนาบสองข้างของ N-Channel เมื่อป้อนแรงดันย้อนกลับ (Reverse Bias) VGS < 0 จะเกิด Depletion Region ขยายตัวบีบช่องทางเดินของอิเล็กตรอน
• เมื่อ VGS = VP (Pinch-off Voltage) ช่องนำกระแสจะถูกบีบจนตัดกระแส (ID = 0)

เปรียบเทียบโหมดของ MOSFET:
• Depletion Mode (D-MOS): มี Channel อยู่แล้ว ป้อน VGS < 0 เพื่อลดกระแส หรือ VGS > 0 เพื่อเพิ่มกระแส
• Enhancement Mode (E-MOS): ไม่มี Channel ปกติตัดกระแส ต้องป้อน VGS > Vth เพื่อดึงอิเล็กตรอนสร้าง Inversion Layer

หลักการจำและวิธีดูสัญลักษณ์ FET ทุกชนิด
1. ทิศทางหัวลูกศร (Arrow Direction):
• ลูกศรชี้เข้า (Point IN): คือ N-Channel (อิเล็กตรอนวิ่งเข้าหา Channel)
• ลูกศรชี้ออก (Point OUT): คือ P-Channel (โฮลไหลออกจาก Channel)
2. ขา Gate & ฉนวน (JFET vs MOSFET):
• JFET: ขา Gate ลาก แตะติดกับเส้น Channel โดยตรง (รอยต่อ PN)
• MOSFET: ขา Gate ลาก เว้นวรรคไม่แตะเส้น Channel (มีฉนวน SiO2 คั่นกั้นกระแส)
3. ลักษณะเส้น Channel (D-MOS vs E-MOS):
• D-MOSFET (Depletion): เส้น Channel ลากเป็น เส้นทึบแถบยาวต่อเนื่อง (Normally ON มีช่องนำกระแสตั้งแต่แรก)
• E-MOSFET (Enhancement): เส้น Channel ลากเป็น เส้นประ 3 ท่อนขาดตอน (Normally OFF ต้องป้อน VGS > Vth เพื่อสร้าง Inversion Layer)
ตารางสรุปเปรียบเทียบสัญลักษณ์ FET ทั้งหมด:
ชนิด (Type) ขั้วเกต (Gate) เส้น Channel หัวลูกศร (Arrow) สภาวะปกติ (VGS = 0)
N-JFET แตะตรง Channel เส้นทึบ ชี้เข้าที่ Gate → ON (นำกระแส IDSS)
P-JFET แตะตรง Channel เส้นทึบ ชี้ออกจาก Gate ← ON (นำกระแส IDSS)

สมการลักษณะเฉพาะหลัก:
• สมการ Shockley (JFET / D-MOSFET):
ID = IDSS · [1 − (VGS / VP)]²
• สมการ E-MOSFET (Square Law):
ID = k · (VGS − Vth)² (เมื่อ VGS ≥ Vth)
• ความชัน Transconductance: gm = ΔID / ΔVGS

หลักการตรวจสอบ FET ด้วยมัลติมิเตอร์:
• MOSFET: ขา Gate ถูกคั่นด้วยชั้นฉนวน SiO₂ ดังนั้นวัดระหว่าง G-S และ G-D ต้องได้ความต้านทานเป็นอนันต์ (O.L / Infinite) เสมอทั้งไปและกลับ
• JFET: ขา G-S และ G-D คือรอยต่อ PN Junction วัดแบบไดโอดจะขึ้นแรงดันตกคร่อม ~0.6–0.7V ในทาง Forward และ O.L ในทาง Reverse
• Body Diode ใน Power MOSFET: วัดระหว่าง D-S จะพบไดโอดป้องกันภายในนำกระแสได้ในทิศทาง Source → Drain
