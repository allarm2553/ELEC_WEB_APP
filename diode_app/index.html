13 Parameters • Standard Semiconductor Physical Models (k, q, T, VF, IS, VT, n, rd, RDC, PIV, trr, Cj, Pmax)
k
Boltzmann's Constant (ค่าคงที่ของโบลต์ซมันน์)
PHYSICS CONSTANT
k = 1.380649 × 10−23 J/K = 8.617 × 10−5 eV/K
ค่าคงที่พื้นฐานทางฟิสิกส์ที่เชื่อมโยงระหว่าง พลังงานจลน์ความร้อน (Thermal Energy) กับ อุณหภูมิสัมบูรณ์ (T ในหน่วยเคลวิน) โดยค่า k·T คือพลังงานความร้อนที่กระตุ้นให้อนุภาคพาหะข้ามรอยต่อ PN
ค่าคงที่ (SI): 1.381 × 10−23 J/K
ค่าในหน่วย eV: 8.617 × 10−5 eV/K
พลังงานที่ 25°C: k·T ≈ 0.0257 eV
บทบาท: กำหนดค่า Thermal Voltage (VT)
q / e
Elementary Charge (ประจุไฟฟ้ามูลฐานของอิเล็กตรอน)
PHYSICS CONSTANT
q = 1.602176 × 10−19 C (คูลอมบ์)
ขนาดของประจุไฟฟ้าของ อิเล็กตรอน 1 ตัว ทำหน้าที่แปลงพลังงานจลน์ความร้อนในหน่วยจูล (Joule) ให้กลายเป็นระดับศักย์ไฟฟ้าหรือ แรงดันไฟฟ้าในหน่วยโวลต์ (Volt = J/C)
ค่าคงที่ (SI): 1.602 × 10−19 C
ความสัมพันธ์พลังงาน: 1 eV = 1.602 × 10−19 J
สมการหลัก: VT = (k × T) / q
หน่วยผลลัพธ์: J / C = โวลต์ (V)
T / TJ
Junction Temperature (อุณหภูมิรอยต่อสารกึ่งตัวนำ)
THERMAL PARAM
T (Kelvin) = T (°C) + 273.15  •  TJ = TA + (PD × θJA)
อุณหภูมิที่เกิดขึ้นจริง ณ รอยต่อ PN ซึ่งเกิดจากอุณหภูมิแวดล้อมรวมกับความร้อนที่เกิดจากกำลังไฟฟ้าสูญเสีย (PD) ส่งผลให้อัตราการสร้างพาหะอิสระเพิ่มขึ้น และแรงดันกั้นลดลง −2 mV/°C
อุณหภูมิห้องมาตรฐาน: 25°C = 298.15 K
ผลต่อ VD (Knee): ลดลง −2.0 mV / °C
ผลต่อ IS (Leakage): เพิ่ม 2 เท่าทุก +10°C
พิกัดสูงสุด TJ(max): 150°C – 175°C (Silicon)
PD(max) • IF(max)
Maximum Power & Forward Current Ratings (พิกัดกำลังสูญเสียและกระแสสูงสุด)
MAX RATINGS
PD = VD × ID ≤ PD(max)  •  ID(avg) ≤ IF(max)
ขีดจำกัดสูงสุดในการทำงานอย่างปลอดภัย (SOA) เพื่อป้องกันไม่ให้อุณหภูมิที่รอยต่อ P-N สูงเกินขีดจำกัดจนสารกึ่งตัวนำละลายหรือชำรุดเสียหายถาวร
1N4007 (IF(avg)): 1.0 A (PD ≈ 1.0–1.2 W)
1N4148 (IF(avg)): 200 mA (PD ≈ 500 mW)
1N5408 (High Current): 3.0 A
Thermal Derating: ลดพิกัดเมื่อ T > 25°C
VF / Vγ
Forward Voltage Drop / Knee Voltage (แรงดันไบอัสตรง / แรงดันกั้น)
DC PARAM
VF ≈ 0.7V (Si) • 0.3V (Ge) • 0.35V (Schottky) • 1.8–3.2V (LED)
แรงดันตกคร่อมรอยต่อ PN เมื่อไดโอดถูกไบอัสตรงจนเริ่มนำกระแสอย่างมีนัยสำคัญ (Knee Voltage) โดยมีสัมประสิทธิ์อุณหภูมิเป็นลบ (−2 mV/°C)
หน่วย: โวลต์ (V)
Silicon (1N4007): ≈ 0.70 V
Germanium (1N34A): ≈ 0.28 V
Temp Drift: −2.0 mV / °C
IS / IR
Reverse Saturation & Leakage Current (กระแสอิ่มตัวย้อนกลับ)
DC PARAM
IS(T) ∝ T3 × e−Eg / (k·T)  •  เพิ่ม 2 เท่าทุกๆ +10°C
กระแสที่เกิดจากพาหะส่วนน้อย (Minority Carriers) ซึมผ่านรอยต่อขณะไบอัสย้อนกลับ มีค่าน้อยมากในระดับ nA ถึง pA แต่ไวต่ออุณหภูมิสูงมาก
หน่วย: nA / pA / μA
Silicon ที่ 25°C: 10 pA – 10 nA
Germanium: 1 μA – 10 μA
Schottky: ≈ 1 μA – 100 μA
VT
Thermal Voltage (แรงดันไฟฟ้าเนื่องจากความร้อน)
PHYSICS / AC
VT = (k × T) / q ≈ 25.85 mV ≈ 26 mV (ที่ T = 25°C / 298.15 K)
พลังงานความร้อนเฉลี่ยของอิเล็กตรอนต่อหนึ่งหน่วยประจุ เป็นพารามิเตอร์พื้นฐานในสมการช็อคลีย์และใช้คำนวณความต้านทานไดนามิก rd
หน่วย: มิลลิโวลต์ (mV)
ที่ 0°C (273K): 23.5 mV
ที่ 25°C (298K): 25.85 mV
ที่ 100°C (373K): 32.1 mV
n / η
Ideality / Emission Factor (สัมประสิทธิ์ความเป็นอุดมคติ)
PHYSICS / AC
ID = IS · (eVD / (n·VT) − 1)  •  n = 1.0 – 2.0
ระบุกลไกการเคลื่อนที่ของพาหะ โดย n = 1 บ่งบอกถึงการแพร่ (Diffusion-dominated) และ n = 2 บ่งบอกถึงการรวมตัวใหม่ในรอยต่อ (Recombination in Depletion Region)
หน่วย: ไม่มีหน่วย (Factor)
Germanium: n ≈ 1.0
Silicon (1N4007): n ≈ 1.05 – 1.8
LED / Compound: n ≈ 1.5 – 2.2
rd
Dynamic / AC Resistance (ความต้านทานพลวัต / สัญญาณขนาดเล็ก)
AC MODEL
rd = Δvd / Δid = (n × VT) / ID ≈ 26 mV / ID(mA)
ความต้านทานสัญญาณขนาดเล็ก (Slope ของเส้นสัมผัสบนกราฟ I-V) ที่จุดทำงาน Q-Point มีค่าแปรผกผันกับกระแส ID โดยตรง
หน่วย: โอห์ม (Ω)
ที่ ID = 1 mA: rd ≈ 26.0 Ω
ที่ ID = 10 mA: rd ≈ 2.6 Ω
ที่ ID = 26 mA: rd ≈ 1.0 Ω
RDC
Static / DC Resistance (ความต้านทานไฟฟ้ากระแสตรง)
DC PARAM
RDC = VD / ID (อัตราส่วนแรงดันต่อกระแสที่จุด Q)
ความต้านทานรวมในวงจร DC วัดจากความชันของเส้นตรงลากจากจุดกำเนิด (0,0) ไปยังจุดทำงาน Q(VD, ID) จะมีค่าสูงกว่า rd เสมอ
หน่วย: โอห์ม (Ω) / กิโลโอห์ม (kΩ)
ที่ (0.7V, 10mA): RDC = 70.0 Ω
ที่ (0.6V, 1mA): RDC = 600 Ω
ขณะ Reverse: RDC > หลายสิบ MΩ
VBR / PIV
Peak Inverse & Breakdown Voltage (แรงดันพังทลาย / แรงดันย้อนกลับสูงสุด)
MAX RATINGS
PIV ≥ Vpeak(rev)  •  VBR (Zener / Avalanche Breakdown)
แรงดันย้อนกลับสูงสุดที่ไดโอดสามารถทนได้โดยไม่เกิดการพังทลาย หากเกินพิกัดจะเกิด Avalanche/Zener Breakdown ทำให้กระแสย้อนกลับพุ่งสูงอย่างรวดเร็ว
1N4007 (PIV): 1000 V
1N4148 (PIV): 100 V
1N5819 (Schottky): 40 V
Zener BZX55C5V1: VZ = 5.1 V
trr
Reverse Recovery Time (เวลาการคืนสภาพย้อนกลับ)
SWITCHING / AC
trr = ts (Storage Time) + tt (Transition Time)
ระยะเวลาที่ไดโอดต้องใช้ในการกำจัดพาหะส่วนน้อยที่ค้างอยู่ในรอยต่อ เพื่อเปลี่ยนสถานะจากนำกระแส (ON) เป็นปิดกั้นกระแส (OFF) เป็นตัวจำกัดความถี่สูงสุดในการสวิตชิ่ง
หน่วย: นาโนวินาที (ns) / ไมโครวินาที (μs)
1N4007 (Standard): ≈ 2 μs (50/60 Hz เท่านั้น)
1N4148 (Fast Switch): ≈ 4.0 ns
Schottky (Majority): < 10 ps (เกือบ 0)
Cj • Cd
Junction & Diffusion Capacitance (ความจุไฟฟ้าแฝงที่รอยต่อ)
AC MODEL
Cj ∝ 1 / (V0 − VD)m (Reverse)  •  Cd ∝ ID × τ (Forward)
Cj (Transition Capacitance) เกิดจากประจุในแถบปลอดพาหะขณะไบอัสย้อนกลับ (ใช้ทำ Varactor Diode) ส่วน Cd (Diffusion) เกิดจากประจุที่แพร่ข้ามรอยต่อขณะไบอัสตรง
หน่วย: พิโคฟารัด (pF)
1N4148 (Cj): ≈ 2.0 – 4.0 pF
Varactor Diode: 10 – 100 pF (ปรับจูนตามแรงดัน)
High Frequency: ลด Cj เพื่อเพิ่ม Bandwidth

จำลองสุขภาพไดโอด (Simulated Diode Condition)
เกณฑ์การตัดสินไดโอดดี-เสียด้วยมัลติมิเตอร์:
  • ไดโอดดี (Good): ไบแอสตรงจะขึ้นค่า 0.2V - 0.7V และเมื่อสลับสายไบแอสกลับจะขึ้น O.L (ความต้านทานอนันต์)
  • ไดโอดช็อต (Shorted): วัดได้ 0.00V หรือมีเสียงปี๊บดังทั้งสองทิศทาง
  • ไดโอดขาด (Open): วัดได้ O.L (ไม่นำกระแส) ทั้งสองทิศทาง
