หลักการของ re Model:
• ความต้านทานไดนามิกของรอยต่อ B-E คือ re = VT / IE ≈ 26 mV / IE (ที่อุณหภูมิห้อง 25°C หรือ 300K)
• อิมพีแดนซ์อินพุตฝั่งเบส: Zb = β · re (สะท้อนค่า re ขึ้นมาเป็น β เท่า)
• แหล่งจ่ายกระแสเอาต์พุต: ic = β · ib = α · ie
• ความต้านทานเอาต์พุต: ro = VA / IC (Early Effect)

วงจรสมมูล Two-Port Network ไฮบริดพารามิเตอร์ (h-Parameter)
วงจร Two-Port Hybrid Equivalent Circuit (Common Emitter)
ระบบสมการ Two-Port h-Parameter:
• v1 = hie · i1 + hre · v2 (สมการอินพุต KVL)
• i2 = hfe · i1 + hoe · v2 (สมการเอาต์พุต KCL)
ความหมายของแต่ละพารามิเตอร์:
1. hie (Input Impedance): ความต้านทานอินพุตขณะช็อตเอาต์พุต (v2 = 0) มีค่า ≈ β · re (Ω หรือ kΩ)
2. hfe (Forward Current Gain): อัตราขยายกระแสไปข้างหน้า มีค่า ≈ βac
3. hre (Reverse Voltage Ratio): อัตราส่วนแรงดันสะท้อนกลับ มีค่าน้อยมาก (~10⁻⁴ นิยมตัดทิ้งเป็น 0)
4. hoe (Output Admittance): ความนำไฟฟ้าเอาต์พุตขณะเปิดอินพุต มีค่า ≈ 1 / ro (μS)

โหมด: ผังวงจรจริง (Complete Circuit)
Common Emitter (CE) มีบายพาส CE:
• Zin: RB || (β · re) (ปานกลาง ~1 kΩ ถึง 3 kΩ)
• Zout: RC || ro ≈ RC
• Voltage Gain (Av): −(RC || RL) / re (Gain สูงมาก สัญญาณกลับเฟส 180°)
• Current Gain (Ai): ≈ β · [RB / (RB + β·re)]
