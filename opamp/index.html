มโนทัศน์สำคัญ: มโนภาพเสมือนลัดวงจรและเสมือนกราวด์ (Virtual Short & Virtual Ground):
• Virtual Short (ลัดวงจรเสมือน): เมื่อต่อแบบป้อนกลับลบ (Negative Feedback) อัตราขยายเปิดมหาศาล (AOL ≈ 105) จะบีบให้ความต่างศักย์ Vd = V+ − V− ≈ 0V ทำให้ V− ≈ V+ เสมอ
• Virtual Ground (เสมือนกราวด์): ในวงจรขยายกลับเฟสที่ต่อ V+ = 0V (ลงกราวด์) ขั้วลบ V− จะมีศักย์เท่ากับ 0V ไปด้วยโดยอัตโนมัติ
• Input Current Iin ≈ 0: เนื่องจาก Zin ≈ ∞ (สูงมาก) ทำให้ไม่มีกระแสไหลเข้าขั้วอินพุตของ Op-Amp (I+ = I− = 0 A)

Open-Loop Gain (AOL) ∞ (อนันต์) 105 − 106 (106 dB) อัตราขยายวงจรถูกกำหนดโดยตัวต้านทานภายนอกเท่านั้น
Input Impedance (Z_{in}) ∞ (อนันต์) 2 M}Ω (FET 1012 Ω) ไม่ดึงโหลดจากแหล่งจ่ายสัญญาณอินพุต (I_{in} ≈ 0)
Output Impedance (Z_{out}) 0 Ω 75 Ω จ่ายแรงดันคงที่ไม่ตกเมื่อต่อโหลดภายนอก
Bandwidth (BW) ∞ (อนันต์) 1.0 MHz} (GBW Product) Gain imes BW มีค่าคงที่ อัตราขยายสูงแบนด์วิดท์จะแคบลง
Slew Rate (SR) ∞ (อนันต์) (ทันทีทันใด) 0.5\ V/μs} (TL082: 13V/μs}) ความเร็วสูงสุดในการเปลี่ยนระดับแรงดันเอาต์พุต (dV/dt)
CMRR (Common Mode) ∞ (อนันต์) 90 dB (30,000 เท่า) หักล้างสัญญาณรบกวนร่วม (Common-mode Noise) ได้ดีเยี่ยม
Input Offset Voltage (V_{OS}) 0 V} 1 - 5 mV} (OP07: 75μV) ความต่างแรงดันอินพุตที่ทำให้เอาต์พุตเท่ากับศูนย์
