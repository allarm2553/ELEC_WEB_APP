สูตรคำนวณจุดทำงาน (DC Operating Point):
• IC(sat) = VCC / RC = 12.0 mA (จุดตัดแกนตั้งเมื่อ VCE = 0)
• VCE(cutoff) = VCC (จุดตัดแกนนอนเมื่อ IC = 0)
• VCE(Q) = VCC − (IC(Q) · RC)
• กำลังงานสูญเสีย: PD = IC(Q) · VCE(Q) (ต้องไม่เกินพิกัด PD(max))

Diode Test — B(+🔴) → E(−⚫)
✔ NPN — รอยต่อ B-E ไบแอสตรงปกติ
หลักการทดสอบ BJT ด้วยย่านวัดไดโอด (Diode Test Method):
1. 🔴 สายแดงที่ Base (B) + ⚫ สายดำที่ Emitter (E) → อ่านได้ ~0.6–0.7 V (รอยต่อ B-E ไบอัสตรง)
2. 🔴 สายแดงที่ Base (B) + ⚫ สายดำที่ Collector (C) → อ่านได้ ~0.6–0.7 V (รอยต่อ B-C ไบอัสตรง)
3. สลับสายวัดกลับทิศ → ต้องขึ้น OL (Over Limit / Reverse Bias ตัดกระแส)
4. วัดระหว่าง C และ E ทั้งสองทิศ → ต้องขึ้น OL ทั้งคู่ (ถ้าได้ 0.00V แสดงว่าชอร์ตทะลุ)
