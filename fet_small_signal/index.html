— กราฟ ID vs VGS (สมการช็อกลีย์) — เส้นสัมผัสความชัน (Tangent Line = gm) ⬤ จุดทำงาน Q-Point
Transconductance (gm): คืออัตราส่วนการเปลี่ยนแปลงของกระแสเดรนต่อการเปลี่ยนแปลงของแรงดันเกต-ซอร์ส gm = ΔID / ΔVGS = (2 · IDSS / |VP|) · (1 − VGS / VP)
• ที่ VGS = 0V จะได้ค่าความนำถ่ายโอนสูงสุด gm0 = 2 · IDSS / |VP|
• ที่ VGS = VP ค่า gm จะลดลงเป็น 0 mS (Cutoff)

การวิเคราะห์สัญญาณขนาดเล็ก:
• สัญญาณเอาต์พุตมีขนาดเท่ากับ Av · Vin
• หากไม่มี CS บายพาส อัตราขยายจะลดลงเหลือ Av = −(gm · RD) / (1 + gm · RS) เนื่องจากเกิด Negative Feedback ที่ขา Source ทำให้วงจรมีเสถียรภาพสูงขึ้น
ตารางเปรียบเทียบ BJT vs FET ในงานสัญญาณขนาดเล็ก
พารามิเตอร์ (Parameter)BJT (Bipolar)FET (JFET / MOSFET)ความหมายและการใช้งาน
กลไกการควบคุมCurrent-Controlled (IB)Voltage-Controlled (VGS)FET ไม่ดึงกระแสจากอินพุต (IG ≈ 0)
Input Impedance (Zin)ปานกลาง (1 kΩ – 50 kΩ)สูงมาก (1 MΩ – 10¹² Ω)FET เหมาะต่อตรงกับเซนเซอร์ความต้านทานสูง
Transconductance (gm)สูงมาก (~40 · IC ≈ 40 mS)ปานกลาง (1 mS – 15 mS)BJT ให้ Gain สูงกว่าในกระแสเท่ากัน
สัญญาณรบกวน (Noise)มี Shot Noise จากรอยต่อ P-Nต่ำมาก (Low Thermal Noise)FET นิยมในเครื่องเสียง Hi-Fi และ RF Front-End
เสถียรภาพอุณหภูมิเสี่ยงต่อ Thermal Runawayมี Negative Temp CoefficientFET ปลอดภัยกว่าเมื่ออุณหภูมิสูงขึ้น
โครงแบบเทียบเคียงCE / CC / CBCS / CD / CGการคำนวณวงจร AC มีรูปแบบคล้ายคลึงกัน
หลักเกณฑ์การเลือกใช้งานในทางปฏิบัติ:
1. เลือก FET: เมื่อต้องการขยายสัญญาณจากแหล่งที่มีอิมพีแดนซ์สูงมาก เช่น หัวไมโครโฟนคอนเดนเซอร์, Piezo sensor, กีตาร์ไฟฟ้า, หรือต้องการสัญญาณรบกวนต่ำมาก
2. เลือก BJT: เมื่อต้องการอัตราขยายแรงดันสูงมากในภาคขยายสัญญาณระดับกลาง หรือต้องการขับกระแสโหลดที่สูง
