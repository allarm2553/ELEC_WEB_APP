หลักการทำงานของ Positive Shunt Clipper:
• ในช่วงไซเคิลบวก: Vin > VD ไดโอดได้รับไบอัสตรง (Forward Bias ON) นำกระแสลัดสัญญาณลงกราวด์ แรงดันเอาต์พุตจึงถูกจำกัดอยู่ที่ Vout = +VD ≈ +0.7V
• ในช่วงไซเคิลลบ: ไดโอดได้รับไบอัสกลับ (Reverse Bias OFF) เปิดวงจร ทำให้สัญญาณ Vout = Vin ผ่านออกไปได้เต็มคลื่น

หลักการทำงานของ Clamper (วงจรยกระดับสัญญาณ):
• วงจร Clamper ทำหน้าที่เพิ่มระดับแรงดันไฟฟ้ากระแสตรง (DC Level) ให้กับสัญญาณ AC โดย ไม่เปลี่ยนรูปทรงและค่าแรงดัน Peak-to-Peak (Vp-p) ของสัญญาณ
• ในช่วงครึ่งไซเคิลแรก ไดโอดจะนำกระแสชาร์จประจุเข้าตัวเก็บประจุ C จนเต็มเท่ากับ VC = Vm − VD
• ในไซเคิลถัดมา ไดโอดจะ OFF ตัวเก็บประจุจะทำหน้าที่เสมือนแบตเตอรี่อนุกรมกับอินพุต ส่งผลให้ Vout = Vin + VC

หลักการทำงานของ Voltage Multiplier:
• วงจรทวีแรงดันใช้การจัดเรียงไดโอดและตัวเก็บประจุแบบขั้นบันได (Cockcroft-Walton Cascade Ladder)
• ในครึ่งไซเคิลลบ: ไดโอด D1 นำกระแสชาร์จประจุ C1 จนมีแรงดัน VC1 = Vm
• ในครึ่งไซเคิลบวก: ไดโอด D2 นำกระแสส่งผลให้แรงดันอินพุตบวกกับ VC1 รวมเป็น 2·Vm ชาร์จประจุเข้า C2
• การเพิ่มคู่ขั้น D3, C3 และ D4, C4 จะช่วยให้ได้แรงดันสูงขึ้นเป็น 3·Vm และ 4·Vm ตามลำดับ โดยไม่ต้องใช้หม้อแปลงขนาดใหญ่

ข้อสังเกตการวิเคราะห์รูปคลื่น:
• Clipper: ตัดทอนหรือจำกัดขนาดแอมพลิจูดของคลื่นด้านใดด้านหนึ่ง
• Clamper: รักษารูปทรงคลื่นเดิมไว้ครบถ้วน แต่ยกแกนอ้างอิง DC ให้สูงขึ้นหรือต่ำลง
• Multiplier: เปลี่ยนสัญญาณ AC เป็นแรงดัน DC บริสุทธิ์ที่มีค่าสูงเป็น 2×, 3×, 4× ของ Vm
